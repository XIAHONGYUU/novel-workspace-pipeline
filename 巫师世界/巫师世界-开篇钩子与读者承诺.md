# 《巫师世界》开篇钩子与读者承诺

## 立即钩子

马车颠簸→少年醒来→"安格列二少爷？"→穿越确认。标准但有效的穿越开篇。环丁鱼（长着小孩脸的鱼）提供第一笔世界观差异。

## 题材承诺

- **核心类型**：异世界转生 + 巫师修炼 + 芯片辅助
- **世界观承诺**：中世纪欧洲风格 + 巫师/魔法元素 + 贵族政治
- **金手指承诺**：生物芯片——分析能力辅助（非战斗型金手指，强调智力成长）
- **成长路线**：贵族子弟→巫师学徒→正式巫师→……

## 主角承诺

- **初始状态**：穿越者+贵族次子，有资源但不高调
- **性格特征**：理性、务实、谨慎
- **成长驱动力**：在残酷的巫师世界中生存下去

## 三章拉力

- 第1章：穿越+身份确认→"这是个什么世界？"
- 第2章：记忆整合+流犯威胁→"这个世界有多危险？"
- 第3章：势力版图+巫师暗示→"巫师的真相是什么？"

## 校验关键词

开篇钩子 / 穿越 / 安格列 / 巫师世界 / 芯片 / 贵族 / 环丁鱼 / 中世纪
