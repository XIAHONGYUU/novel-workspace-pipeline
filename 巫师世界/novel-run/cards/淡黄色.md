# 淡黄色

## 简述

淡黄色的墙面，尖锐的建筑顶，就像是城堡的顶端，又像是一个个教堂

## 证据片段

- 淡黄色的墙面，尖锐的建筑顶，就像是城堡的顶端，又像是一个个教堂
- 门打开后，里面是一条黑褐色的石质走廊，两侧墙上开着小天窗，淡黄色的阳光从右边的天窗斜斜射进来，打在黑色地面上，一股阴冷潮湿的空气扑面而来
- 淡黄色的卷轴用红色丝线捆了一个活结
- 淡黄色的皮纸上，用黑色笔迹清晰地记录着工整的文字
- 右边的前方麦田里，一处高一些的田坎上，一座淡黄色风车磨坊慢慢地接近着
- ※※※　　淡黄色的墓穴卧室内，墙壁上挂着一盏黑色半圆油灯，左右两点拇指大的火光着凉了整个卧室，显得有些昏暗
- ※※※　　半小时后……　　淡黄色墓穴治疗室内
- 整个墓穴房间都是淡黄色的石砖墙壁，连同地面也是一样颜色，治疗室只是一件正方形的小房间，并排摆放了四张灰白地铺，作为病床，一张柜子和一套桌椅就是全部的家具
