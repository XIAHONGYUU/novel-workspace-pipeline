# 红光

## 简述

眉心红蝎子的印记陡然浮现出来，散发出明艳的红光，不断吸收着射来的红光

## 证据片段

- 眉心红蝎子的印记陡然浮现出来，散发出明艳的红光，不断吸收着射来的红光
- 双目紧闭，安格列坐在书房里，胸口的两个印记陡然红光大作，隐隐有些刺目起来
- 红光缓缓汇聚成一条红色能量丝带，缓缓围绕着安格列开始旋转
- 红色祭坛符纹边，还有着另外一幅略微小一些的复杂符纹，同样是暗红色，却闪烁着更为浓烈红光
- 安格列静静站在符纹边，手中拿着刚刚撕下来的手臂皮肤，上边镌刻着五个红光符纹
- 红光陡然一变，迅速转化为刺目的蓝光
- “我感觉这里跳动着活跃的意志意念……”他双目泛起淡淡红光，闭上眼，手指缓缓按在符号上
- 黑色蝎钳虚影泛着红光，和符号表面的无形力量相抵，僵持不下
- 安格列加大力度，手指泛起红光，再度敲在屏障上
- 红光中的风暴元素还没靠近，便开始浑身冒烟，身体蜡烛般融化起来，他们张开嘴，却来不及发出任何声音，一个个的迅速化为一摊摊蓝色液体留在甲板上，表面还泛着淡淡电弧
