# 凝聚成一

- 首次出现：第518章 梦魇 3 (chunk-0521)
- 提及次数：4

## 简述

波纹迅速凝聚成一朵紫色花苞，缓缓绽放

## 证据片段

- 波纹迅速凝聚成一朵紫色花苞，缓缓绽放
- 烟雾缓缓凝聚成一面巨大的紫色镜面，上边浮现出清晰的红色场景
- 脚尖轻轻点在草地上，男子手一扬，草坪上的泥土和青草缓缓融化成一团，然后液体般飞起，凝聚成一层淡绿色铠甲覆盖在他身上
- 而在他原本所站的地方，一团暗红火焰凭空燃起，凝聚成一个一模一样的人形，人形身体刚开始是半透明，随着时间流逝，身体渐渐实质稳定下来
