# 《巫师世界》主角锚点与骨架

## 说明

本文件用于在正式拆安格列的人物卡和词条体系之前，先稳定确认主角锚点与主角骨架。

## 一、主角锚点

- 本名：安格列
- 常见称谓：安格列阁下、安格列大人、学徒时期的安格列
- 化名 / 马甲：当前整理中以本名为主，重点不在多重化名而在阶段身份抬升
- 易混简称：安格、格列
- 关键关联名词：芯片、药剂、血脉、冥想法、梦魇、世界石、真身、领主

## 二、当前确认依据

- 从整套人物卡与词条体系看，安格列是贯穿全书的稳定主角
- 从成长链条看，芯片、药剂、实验、血脉和梦魇等核心内容都围绕他展开
- 从世界结构展开看，主角视角贯穿学院、组织、高位巫师、梦魇与终局设定

## 三、主角骨架草稿

### 1. 身份底座

- 贵族后裔
- 带芯片优势的穿越式理性成长者
- 从学徒一路抬升的巫师主角

### 2. 成长引擎

- 芯片辅助
- 药剂与实验线
- 冥想法、巫术、符文和等级体系
- 血脉、龙印、真身与高位形态变化

### 3. 质变路线

- 从学徒到高位巫师的等级抬升
- 从实验与资源积累到形态和阶段质变
- 从单体成长到高位结构参与

### 4. 高位结构

- 学院与组织体系
- 梦魇与世界石
- 概念武装与更高世界结构
