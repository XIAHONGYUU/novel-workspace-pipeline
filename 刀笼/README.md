# 刀笼 工作区说明

本目录是《刀笼》的独立工作区。

## 当前结构

- `source/刀笼.md`
  原始文本副本
- `source/`
  原文与转换稿目录
- `work/`
  chunk、抽取、合并与 focus 产物目录
- `刀笼-项目启动清单.md`
  当前项目 checklist
- `刀笼-整书粗阶段划分.md`
  第一轮 chunk 蒸馏时使用的阶段划分文件
- `刀笼-主角锚点与骨架.md`
  主角骨架入口
- `工作状态-YYYY-MM-DD.md`
  当前项目阶段性交接文件

## 建议顺序

1. 放入原文
2. txt 转 md
3. 跑 chunk / AI 人物抽取 / focus
4. 写阶段划分
5. 写主角骨架
6. 写主角总卡
7. 拆一级词条
8. 补核心体系总览与全书精华总结
