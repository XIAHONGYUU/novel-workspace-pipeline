# 《刀笼》整书粗阶段划分

## 说明

本文件用于把《刀笼》的主角主线按成长与场域变化做粗粒度收束，方便后续词条、人物卡和体系总览互相对照。

## 阶段 1：黑山城与底层求生期

- 起止范围：开篇至黑山城与刀匠行体系基本立住
- 划分依据：主角仍主要被底层生存、伤病、锻匠身份和地方秩序所束缚
- 主角状态：带伤生存者、锻匠、在险局中试探立足
- 主要地点 / 场域：黑山城、山南道、刀匠行
- 主要矛盾：生存压力、地方秩序压制、江湖与兵灾环境
- 主要抬升：从单纯求活过渡到以刀、身手、判断力入局

## 阶段 2：江湖入局与戚大寇成形期

- 起止范围：从地方求生转向更明确的江湖角色与声名建立
- 划分依据：主角身份开始由锻匠向能打、能杀、能承担局势的人切换
- 主角状态：入局者、刀道上升者、逐渐形成戚大寇名号
- 主要地点 / 场域：江湖行动路线、地方势力节点、各类冲突场
- 主要矛盾：江湖秩序、敌对势力、不断升级的正面冲突
- 主要抬升：锻刀与刀道路线、战斗方式、身份变化同步成形

## 阶段 3：龙脉、真神与高位结构抬升期

- 起止范围：从中层强者路线进入龙脉、真神与更高修行结构
- 划分依据：主角成长不再只是江湖刀客层面，而开始进入高位体系
- 主角状态：更高层的局中人、龙脉与真神路线参与者
- 主要地点 / 场域：龙脉相关场域、真神路线结构、关键高位冲突节点
- 主要矛盾：修行层级抬升、高位对手、结构型大局卷入
- 主要抬升：龙脉、修行与真神路线成为核心解释轴

## 阶段 4：夜昼国、上古投影与终局高位期

- 起止范围：进入夜昼国、上古世界投影和更高位格局后段
- 划分依据：主角已经不再只是局部强者，而是进入终局级结构
- 主角状态：高位参与者、龙脉终局变化承接者
- 主要地点 / 场域：夜昼国、不周、上古世界投影、终局高位场域
- 主要矛盾：高位秩序、天帝天母、不周与终局对抗
- 主要抬升：从局中强者转向更高位结构中的关键变量
