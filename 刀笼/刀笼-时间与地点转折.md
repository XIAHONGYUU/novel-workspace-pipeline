# 《刀笼》时间与地点转折

## 时间转折

戚笼从青年到龙脉之王的时间跨度与成长线绑定。底层阶段时间紧实（密集生存压力和快速身份试探），高位阶段时间舒缓（需要世界观铺垫和认知消化）。没有明显的"时间跳跃偷懒"问题。

## 地点转折

- **黑山城 → 江湖**：从匠户工场到开放世界，身份从固定切换到流动
- **江湖 → 夜昼国**：从"人杀人"的局部对抗进入国家层面
- **九州 → 上古世界投影**：从人间进入异常空间，世界边界不再封闭
- **不周 → 终局**：不周不只是地点，而是"世界根部问题"的空间化

## 时间与地点联合判断

《刀笼》的地点和时间推移严格对应主角成长层级。场域越大、时间越靠后，戚笼的身份越高。每次地点扩边时机得当——不会在旧场域耗尽前急于打开新地图。上古世界投影和神墓这些"异常地点"让高位内容有了空间载体，而不是飘在抽象设定里。
