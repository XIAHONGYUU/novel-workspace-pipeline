# 《序列大明》整书粗阶段划分

## 说明

本文件用于在首轮 chunk 蒸馏之后，把《序列大明》的主线按“李钧的身份换层”和“活动场域抬升”重新钉稳。

这本书的阶段切分，不适合只按战力等级来分，更适合同时看三条线：

- 李钧站在什么身份上
- 他卷进了哪一层势力结构
- 活动空间从哪里扩到了哪里

## 阶段 1：成都府鸡鹅区潜伏与武九破锁期

- 起止 chunk / 章节：前言 - 第79章（约 `chunk-0001` - `chunk-0080`）
- 划分依据：
  - 开局主场始终围绕成都府鸡鹅区、鬼街、九龙街
  - 李钧的底层身份仍是浑水袍哥红旗五哥兼锦衣卫线人
  - 主线目标是查叛徒、活下来、完成武序第一次破锁
- 主角在这个阶段的状态：
  - 仍是底层罪民秩序里的狠角色
  - 依靠武道精通面板、铁布衫、青帝诀和血战临门逐步抬升
  - 在祭刀会、赵斗、罗镇压力下完成 `武道序列九-暴徒` 晋升
- 主要地点 / 场域：
  - 成都府
  - 鸡鹅区
  - 鬼街
  - 九龙街
- 主要矛盾：
  - 袍哥会内鬼与祭刀会冲突
  - 赵鼎、赵斗、罗镇三方压力
  - 李钧必须在黑帮规则和官面力量夹缝中自保
- 主要抬升：
  - 从普通打手抬成真正的从序者
  - 从“可被利用的线人”抬成鸡鹅区必须认真对待的变量

## 阶段 2：成都府风暴扩面与锦衣卫暗线入局期

- 起止 chunk / 章节：第80章 - 第158章（约 `chunk-0081` - `chunk-0160`）
- 划分依据：
  - 李钧不再只围着街区黑帮线打转，而是正式接入顾邕、顾氏、锦衣卫和三教门阀暗线
  - “十二条序列”“六艺芯片”“黄粱硕鼠”等世界信息密集展开
  - 鸡鹅区仍是底座，但主线已经转向更大的结构斗争
- 主角在这个阶段的状态：
  - 从鸡鹅区武九暴徒，转成能被顾邕和余寇拿来落子的人
  - 对三教九流、序列门槛、黄粱和帝国阶级秩序开始形成系统认知
  - 逐步脱离纯袍哥身份，开始踩进顾氏和锦衣卫的中间层
- 主要地点 / 场域：
  - 成都府
  - 教坊司
  - 蜀道物流相关场域
  - 顾氏与锦衣卫暗线网络
- 主要矛盾：
  - 锦衣卫要借李钧撬动顾氏
  - 顾邕则把李钧当成可用的血肉武夫
  - 李钧必须在“被招安”和“被吃掉”之间抢主动权
- 主要抬升：
  - 主角的世界认知从街区扩到帝国结构
  - 李钧第一次真正看见黄粱、芯片、门阀与皇权之间的深层关系

## 阶段 3：重庆佛国、黄粱梦境与矩子堂换层期

- 起止 chunk / 章节：第159章 - 第318章（约 `chunk-0161` - `chunk-0320`）
- 划分依据：
  - 主场明显从成都府局部，转到重庆府、洪崖山、南渝等新场域
  - 陈乞生、赵青侠、袁明妃、矩子堂等节点集中出现
  - 李钧开始在黄粱佛国、意识幻境、墨家机关和更复杂的序列结构中活动
- 主角在这个阶段的状态：
  - 不再只是街头杀出来的武夫，而是能在佛国、梦境、机关和矩子堂事务里立足的人
  - 墨甲、飞剑、绣春刀、劲力武学开始真正融合
  - 身边开始稳定形成以邹四九、陈乞生、赵青侠等人为代表的主角关系层
- 主要地点 / 场域：
  - 重庆府
  - 洪崖山
  - 南渝区
  - 黄粱佛国与相关梦境场域
- 主要矛盾：
  - 佛国意识控制与黄粱网络风险
  - 墨家与敌对势力的连环博弈
  - 李钧要在更高密度的结构里保持自我而不是被度化或被利用
- 主要抬升：
  - 主角的战斗和认知第一次摆脱单一“街头械斗”层次
  - 李钧开始具备兼顾肉身武力、机关装备和意识层风险的复合型主角特征

## 阶段 4：荒世、青城与新政结构抬升期

- 起止 chunk / 章节：第319章 - 第478章（约 `chunk-0321` - `chunk-0480`）
- 划分依据：
  - “荒世集团”“青城”“新政”“矩子堂”“外聘客卿”等关键词持续出现
  - 李钧已不再只是执行者，而开始和政策、组织、宗门寡头结构正面对接
  - 这一阶段是从中层强者迈向帝国棋局关键变量的桥梁
- 主角在这个阶段的状态：
  - 战斗配置更稳定，墨甲与武学的配合更成熟
  - 能独立判断并影响组织决策
  - 开始对“谁在操盘帝国局势”有更清晰的认知
- 主要地点 / 场域：
  - 青城相关区域
  - 荒世集团体系
  - 帝国内部新政推进场域
  - 更高层的道序、墨序、官面网络
- 主要矛盾：
  - 新政与旧势力之间的对撞
  - 李钧所在阵营与更高组织之间的拉扯
  - 如何把个人暴徒式上升转成结构内可持续的抬升
- 主要抬升：
  - 李钧从局中悍将逐步转成组织层的关键支点
  - 书的重点从“他能不能打赢”明显扩展到“他怎么接住更大盘子”

## 阶段 5：倭区、番地与跨域大战扩边期

- 起止 chunk / 章节：第479章 - 第638章（约 `chunk-0481` - `chunk-0640`）
- 划分依据：
  - 明确出现江户、倭区、番地、阁皂、武当、黄粱海兽等跨区域节点
  - 主角活动范围全面跳出单一州府
  - 战争、跨域远征、异地宗教与地缘冲突成为主线重心
- 主角在这个阶段的状态：
  - 已是可以跨区作战和解决高危结构问题的硬核执行者
  - 既能正面砍杀，也能在外域结构中辨认势力关系和借力
  - 其“武夫”标签开始带上更强的帝国性和远征性
- 主要地点 / 场域：
  - 倭区
  - 江户
  - 阁皂道城
  - 武当相关场域
  - 番地与黄粱相关外域空间
- 主要矛盾：
  - 倭区与大明之间的跨域冲突
  - 外域势力与本土势力的碰撞
  - 李钧如何在不断扩张的战场里维持主线控制力
- 主要抬升：
  - 空间版图显著扩边
  - 李钧从地方强者彻底变成可在帝国外缘和异域盘面行动的主角

## 阶段 6：青城失蜀、山巅订战与帝国终局压力期

- 起止 chunk / 章节：第639章 - 第718章（约 `chunk-0641` - `chunk-0720`）
- 划分依据：
  - 出现“青城失蜀”“订战山巅”“好大个皇帝”“张峰岳”等终局味道很重的节点
  - 李钧回到熟悉却已换层的成都 / 鬼街一带，但已不是最初的鸡鹅区视角
  - 个人恩怨进一步并入帝国高层秩序、皇权和大人物博弈
- 主角在这个阶段的状态：
  - 已能直接对接帝国高层问题
  - 对张峰岳这类大节点人物的态度和选择，决定他不再只是工具，而是有立场的局中人
  - 空间上回返故地，结构上却站到了远高于开篇的位置
- 主要地点 / 场域：
  - 成都相关旧地
  - 青城山
  - 山巅战场
  - 帝国核心权力辐射区
- 主要矛盾：
  - 谁来定义大明秩序的下一阶段
  - 李钧如何在旧秩序废墟与新秩序压力之间保住自己的方向
  - 与张峰岳、皇帝和更高层力量之间的冲突与对位
- 主要抬升：
  - 终局层面的身份和立场被钉实
  - 李钧正式完成从“鸡鹅区武夫”到“帝国高压结构关键变量”的最后跃迁

## 番外说明

- 这些内容主要起补完与回看作用，不改变主干阶段判断
- 主线闭环判断以第718章前后的主体推进为准
