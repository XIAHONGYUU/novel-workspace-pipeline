# 《永恒剑主》主角锚点与骨架

## 说明

本文件用于在正式拆主角人物卡和词条之前，先稳定确认主角锚点与主角骨架。

## 一、主角锚点

- 本名：林新
- 常见称谓：大师兄、林新如身份外壳下的实际主角
- 化名 / 马甲：随阶段可能接入更高位身份，但主锚点始终是林新这条成长线
- 易混简称：林新 / 林新如记忆壳层
- 关键关联名词：红松门、秘技、红花剑、幽府、原能使、原初、永恒

## 二、当前确认依据

- 从 chunk 蒸馏结果看：开局到终局都持续围绕林新的生存、成长和高位收束推进。
- 从 focus 追踪结果看：当前主线冲突和体系升级都以林新为稳定中心。
- 从阶段划分看：每次阶段换挡，本质上都是林新的身份、能力和世界位置升级。

## 三、主角骨架草稿

### 1. 身份底座

林新的身份底座是穿越后的弱势门派大师兄外壳，他不是天然高位者，而是靠判断、外挂和持续升级逐步抬高自己的位置。

### 2. 成长引擎

成长引擎来自两个部分：一是这个世界本身残酷、资源与暴力密度高；二是林新能不断把生存压力转成可追的成长收益。

### 3. 质变路线

质变路线不是单点爆发，而是从地方求生、体系接入、能力加深到世界高位问题承接的连续升级。

### 4. 高位结构

高位结构最终会落到原初、永恒和终局层面，说明这条主角线不是地方爽点短跑，而是长线抬升后再统一回收。
