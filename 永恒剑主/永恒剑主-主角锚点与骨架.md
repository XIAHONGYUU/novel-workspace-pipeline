# 《永恒剑主》主角锚点与骨架

## 说明

本文件用于在正式拆主角人物卡和词条之前，先稳定确认主角锚点与主角骨架。

## 主角锚点

- 本名：林新（穿越前原名）/ 林新如（此世身份，富商之子、红松门大师兄）
- 常见称谓：大师兄（安颖、路云、路雨称呼）、林新（对外通用）、林家大少爷（林家称呼）
- 化名 / 马甲：杨慎（可能的化名，在work/cards中出现"杨慎（林新）.md"）
- 易混简称：林新如/林新（穿越前后的身份区分）、林摄日（部分别名）
- 关键关联名词：红松门、红松剑、小归元功、秘技（师父临终所传）、属性异能（穿越金手指）、永恒剑主（终局身份）

## 二、当前确认依据

- 从 chunk 蒸馏结果看：全书1004章覆盖红松门求生→地方江湖成长→体系升级→世界扩边→终局收束五阶段，主角在每个阶段都有明确的能力和身份质变
- 从 focus 追踪结果看：主角身份轨迹为 穿越者→红松门大师兄→地方江湖强者→体系能力者→世界结构关键变量→永恒剑主
- 从阶段划分看：五阶段划分确认主角成长不是线性的数值增加，而是每次阶段跃迁都伴随身份、能力、敌我关系和主线问题的同步升级

## 三、主角骨架草稿

### 身份底座

林新的身份底座由三层叠加构成：穿越者林新（现代知识+属性异能外挂）→富商之子林新如（社会资源+家族背景）→红松门大师兄（门派身份+江湖立足点）。这三层身份不是并列的，而是由穿越者意识统合前两层资源，在红松门这一破落平台上完成最艰难的从零到一的起步。身份底座的关键词是"壳层"——林新一开始的身份都是壳层（名义上的大师兄、实际上的弱者），他的成长本质上就是不断把壳层填实、把名义身份变成真实实力的过程。

### 成长引擎

林新的成长引擎由三根支柱驱动：

- **属性异能（金手指）**：穿越附带的能力，具体表现为量化自身属性并进行提升的能力，是成长速度超越常人的根本保障
- **秘技（师父临终所传）**：作为开局的关键资源，秘技不是一次性外挂，而是持续提供成长方向和路线选择的长期引擎
- **修行体系（小归元功→三功六法→地仙大道→永恒路线）**：随阶段升级而不断升级的修行框架，确保成长不撞天花板

三根支柱的协同方式是：属性异能提供成长加速，秘技提供路线选择，修行体系提供框架支撑。没有属性异能，成长太慢；没有秘技，方向不明；没有修行体系，天花板太低。

### 3. 质变路线

林新的质变路线遵循"身份→能力→格局"三级跳模式：

- **第一次质变（阶段1→2）**：从红松门的被动求生到主动参与地方江湖博弈，身份从"门派大师兄"升级为"独立江湖力量"
- **第二次质变（阶段2→3）**：从地方江湖强者升级为体系能力者，通过龙蛇传道打开高位修行体系，能力从地方级跃升为体系级
- **第三次质变（阶段3→4）**：从体系参与者升级为世界结构的关键变量，能力从体系内部竞争升级为对世界规则本身的影响
- **最终质变（阶段4→5）**：从关键变量升级为"永恒剑主"——终极身份的确立不只是武力最强，而是成为世界规则的定义者之一

### 4. 高位结构

林新的高位结构由三个终局命题定义：

- **力量的边界**：属性异能的成长是否有上限？如果有，在哪里？如果没有，无限的成长如何与有限的世界共存？（方狱线承载）
- **剑道的极致**：作为一个以"剑"为名的终极存在，"剑"的终极意义是什么？（红叶剑主线承载）
- **规则的重新定义**：当个人力量超越体系规则时，是摧毁旧规则还是重新定义规则？（九曲仙翁线承载）

这三个命题不是孤立的——它们分别对应林新终局的三个验证维度：个人战力（方狱）、专业极致（红叶剑主）、体系格局（九曲仙翁）。三个维度的同时达成，才是"永恒剑主"的完整定义。
