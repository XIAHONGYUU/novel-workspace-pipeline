# 《永恒剑主》主角锚点与骨架

## 说明

本文件用于在正式拆主角人物卡和词条之前，先稳定确认主角锚点与主角骨架。

## 一、主角锚点

- 本名：林新
- 常见称谓：少爷、师兄、哥哥
- 化名 / 马甲：当前首轮结果里尚未稳定确认，后续需要结合中后期检查点继续补
- 易混简称：林
- 关键关联名词：红松门、红松城、红花剑、幽府、筑基、巨鳐万莎功、帝国、原能使

当前阶段可以稳定用于检索和主角追踪的主锚点，就是 `林新`。

## 二、当前确认依据

- 从 chunk 蒸馏结果看：
  - 首轮诊断报告已经把 `林新` 提到主角候选第一位，文本粗提及约 `25227` 次
  - 第一章 `红松门` 开始就已经稳定以林新为叙事中心
- 从 focus 追踪结果看：
  - `林新` focus 结果覆盖 `1004` 个 chunk
  - 累计提及次数 `20500`
  - 涉及章节数 `984`
  - 从前期到后期都持续作为核心行动者存在
- 从阶段划分看：
  - 当前虽然还没有正式完成整书粗阶段划分，但从 checkpoints 已经能明显看出，这条线至少经历了
  - 红松门与穿越开局
  - 入门、练功、离乡与宗门扩展
  - 筑基、剑派、法剑、幽府相关抬升
  - 帝国、原能使与更大世界结构阶段

所以当前可以基本确认：

《永恒剑主》的稳定主角就是 `林新`。

## 三、主角骨架草稿

### 1. 身份底座

- 穿越者
- 红松门大师兄
- 山下红松城富商之子 / 大少爷
- 从小习武、身处低层门派与地方家族结构中的年轻人

林新的开局不是纯白纸。

他一开始就同时带着两层底色：

- 现代人意识与穿越者视角
- 本地门派弟子与家族少爷身份

这让他既有“外来观察者”的认知优势，也有“本地生存者”的现实束缚。

### 2. 成长引擎

- 核心外挂 / 核心异常能力：幽府相关能力
- 剑与法剑路线：红花剑是早期到中期极关键的兵器与路线锚点
- 练功与持续突破：从秘技、入门到筑基，成长非常明显
- 吸收、炼化、强制灌注式提升：中段已经出现大规模精华涌入与强行吸纳
- 精神力与更高层控制能力：后段已经明显不再只是普通剑修或门派弟子层面

林新的成长不是单一“勤学苦练”，而更像是：

- 外挂
- 功法
- 兵器
- 强制吸收与质变
- 精神与高位控制能力

一起往上推。

### 3. 质变路线

- 第一段质变：从穿越后茫然的红松门大师兄，转成真正开始主动修炼、入局和外出的行动者
- 第二段质变：从地方门派与江湖范围，进入筑基、剑派、法剑、幽府等更高修行结构
- 第三段质变：中段开始出现巨鳐万莎功、精华灌体、修为进无可进等明显高强度抬升
- 第四段质变：后段进入帝国、原能使、群星帝国、风暴帝国等更大结构，已经不是单一地方修士成长线
- 第五段质变：最终进入“永恒”“原初”“毁灭”“钥匙补全”这类更高位问题

这说明林新这条线的核心不是普通升级，而是不断发生结构性跳层。

### 4. 高位结构

- 地方起点：红松门、红松城、小范围门派与家族结构
- 修行中层：筑基、剑派、法剑、幽府、特殊功法
- 更大世界层：帝国、群星帝国、风暴帝国、原能使
- 后段高位层：毁灭、原初、永恒、钥匙补全、极大规模精神力与控制力

也就是说，《永恒剑主》并不是停在一地宗门斗争里，而是明显会一路抬升到更大世界和更高位问题。

## 四、当前最值得拆的一级词条

- 身份变化
- 幽府 / 核心外挂路线
- 剑与法剑路线
- 战斗方式
- 修行 / 筑基 / 高位路线
- 世界结构
- 势力与局势卷入
- 重要关系网
- 重要城市与地域轨迹

## 五、当前阶段性理解

林新这条主角线目前最值得抓住的，不是“他认识了谁”，而是下面这条主干：

- 穿越开局
- 门派与家族底座
- 剑修 / 法剑 / 幽府等核心成长引擎
- 中段不断强制吸收、突破和质变
- 后段进入帝国、原能使与更高位世界结构

这意味着《永恒剑主》的整理方向，应该严格按主角优先法推进：先抓主角主梁，再让词条从主梁里长出来，而不是从全人物产物反推。

## 六、当前结论

当前已经可以稳定确认，《永恒剑主》的主角就是 `林新`。

而从现有 focus 结果看，这不是一个单纯“门派练剑升级”的故事，而是一条从穿越、地方门派、剑修成长，一路推向更大修行结构、帝国格局与高位问题的主角线。

这就是当前继续搭建《永恒剑主》主角全词条百科时，最应该抓住的总骨架。
