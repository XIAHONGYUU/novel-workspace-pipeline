# 《永恒剑主》整书粗阶段划分

## 说明

本文件用于在第一轮 chunk 蒸馏时，同步给整本书做粗粒度阶段划分。

阶段划分可以同时按两种维度做：

- 时间 / 成长阶段
- 地点 / 地图阶段

## 阶段 1：红松门求生与立足期

- 起止 chunk / 章节：开篇至建立红松门基本安全区
- 划分依据：主角寄身于破落门派，名义上是大师兄，实际上要从零开始建立真实的安全感和控制力
- 主角在这个阶段的状态：穿越者适应期，身份是壳层（富商之子、红松门大师兄），真实实力不足，靠应变和判断力求存
- 主要地点 / 场域：红松门、周边地方势力范围
- 主要矛盾：名义身份 vs 实际战力落差；门派破落 vs 外界威胁
- 主要抬升：从被动适应到主动掌控红松门局面

## 阶段 2：地方江湖成长与体系成形期

- 起止 chunk / 章节：红松门稳定后至进入更大江湖体系
- 划分依据：主角不再只是守着一个破落门派，而是开始主动进入地方江湖势力博弈
- 主角在这个阶段的状态：从门派管理者向独立江湖力量转变，战力、身份、资源同时扩张
- 主要地点 / 场域：地方江湖、各门派势力范围、周边城镇和资源点
- 主要矛盾：与地方门派和敌手的对抗；个人成长路线 vs 江湖势力格局
- 主要抬升：秘技和外挂开始转化为长期收益，门派从防守转向扩张

## 阶段 3：体系能力升级与结构对接期

- 起止 chunk / 章节：地方江湖阶段结束后至高位体系介入
- 划分依据：主角的成长不再局限于地方层面的对抗，而是开始碰触更高位的修行体系和势力结构
- 主角在这个阶段的状态：从江湖强者向体系能力者转变，能力和身份开始对接更大格局
- 主要地点 / 场域：更高位的修行场所、帝国和原能使体系、跨区域势力范围
- 主要矛盾：个人能力天花板 vs 更高位体系的壁垒；地方根基 vs 高位资源的取舍
- 主要抬升：修行路线的质变，身份从地方豪强向体系参与者升级

## 阶段 4：世界结构扩边与终局高位期

- 起止 chunk / 章节：高位体系深入后至全书收束
- 划分依据：主角已成为体系中的关键力量，不再只是参与者而是定义者之一
- 主角在这个阶段的状态：高位统合者，身份已超越门派和地域，个人成长与世界结构深度咬合
- 主要地点 / 场域：世界级场域、高位势力核心、终局对抗节点
- 主要矛盾：世界结构的根本冲突；终局对位中的身份定位和结局选择
- 主要抬升：从局部强者到世界结构关键变量的最终跃迁

## 阶段 5：终局收束与永恒剑主落位

- 起止 chunk / 章节：终局对抗至全书结尾
- 划分依据：主角面对的是世界级的收束问题，需要完成全书最长线的身份和路线闭环
- 主角在这个阶段的状态：永恒剑主——全书终极 identity 的最终落位
- 主要地点 / 场域：终局场域
- 主要矛盾：全书主线冲突的最终爆发和收束
- 主要抬升：从高位参与者到\"永恒剑主\"这一终极身份的完全达成
