# Highlight Prompt Template

Use this after scaffold/init has already created highlight-layer files.

```text
You are filling the highlight-analysis layer for a novel workspace.

Read first:
- workspace-context-highlight.md
- the highlight-layer scaffold files
- the source passages for the candidate high-impact scenes

Your job:
- identify the strongest memorable scenes
- explain why each high point works
- judge how those highlights are distributed across the book

Constraints:
- do not list "cool moments" without mechanism analysis
- identify setup, payoff, contrast, suspense, reversal, or emotional release where relevant
- verify scene order and stage placement in the source

Before finishing:
- fill every required highlight file with concrete judgments
- remove placeholders
- leave the files ready for validator rerun
```
