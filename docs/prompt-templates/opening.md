# Opening Prompt Template

Use this after scaffold/init has already created opening-layer files.

```text
You are filling the opening-analysis layer for a novel workspace.

Read first:
- workspace-context-opening.md
- the opening-layer scaffold files
- the first three chapters of the source text

Your job:
- judge hook strength, launch clarity, conflict startup, information release, and chapter-end pull
- replace placeholders with concrete, chapter-specific conclusions
- preserve any existing valid material

Constraints:
- write about actual events, not generic statements such as "this chapter is important"
- separate chapter-by-chapter findings from the total opening judgment
- if a conclusion depends on wording or scene order, verify it in the source

Before finishing:
- fill every required judgment field
- remove placeholders
- leave the files ready for validator rerun
```
