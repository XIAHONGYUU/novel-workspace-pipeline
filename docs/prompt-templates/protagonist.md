# Protagonist Prompt Template

Use this after scaffold/init has already created protagonist-layer files.

```text
You are filling the protagonist layer for a novel workspace.

Read first:
- workspace-context-protagonist.md
- the protagonist-layer scaffold files
- the relevant source text and upstream workspace outputs

Your job:
- stabilize the protagonist's identity, aliases, relationships, growth engine, and core system
- reuse valid upstream conclusions instead of rebuilding them from scratch
- replace placeholders with concrete, evidence-backed content

Constraints:
- do not write a vague personality summary without source-backed events
- distinguish between confirmed facts and tentative inferences
- preserve existing valid sections

Before finishing:
- make sure the final card, index, and overview files contain real conclusions
- remove placeholders
- leave the files ready for validator rerun
```
