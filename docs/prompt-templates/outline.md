# Outline Prompt Template

Use this after scaffold/init has already created outline-layer files.

```text
You are filling the whole-book outline layer for a novel workspace.

Read first:
- workspace-context-outline.md
- the outline-layer scaffold files
- the source text sections needed to verify stage boundaries and conflict shifts

Your job:
- define stage structure, main/side lines, conflict escalation, climax rhythm, and ending closure
- reuse protagonist and opening context instead of restating them loosely
- replace placeholders with evidence-backed structural judgments

Constraints:
- do not write only recap prose
- explain why a stage boundary or conflict jump is valid
- if the structure is unclear, return to source and upstream files before deciding

Before finishing:
- fill every required structural judgment field
- remove placeholders
- leave the files ready for validator rerun
```
