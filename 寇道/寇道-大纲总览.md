# 《寇道》大纲总览

## 一、全书概览

| 维度 | 内容 |
|---|---|
| 书名 | 寇道 |
| 作者 | 虫梦 |
| 主角 | 寇立 |
| 篇幅 | 长篇（源文约240万字） |
| 类型 | 修行/武道/仙侠 |
| 核心方法论 | 武叩仙门——以武道为起点，逐步接入更高修行结构 |

## 二、全书结构主线

《寇道》全书以寇立"从门外求道人到多体系统合者"的成长为主轴，贯穿五个阶段：

```
粤州求道摸索期 → 烧身武馆成形期 → 江湖生死磨砺期 → 武盟与朝廷抬升期 → 神仙道与高位结构期
```

每个阶段的核心推进逻辑为："外部压迫 → 道路判断 → 路线成立 → 世界打开"。

## 三、全书核心命题

1. **路线的选择与校正**：寇立不是被动升级，而是主动判断"该走哪条路"，并在每一条路上反复校正自己的方向选择。
2. **身体即道路**：武道的核心不是招式而是身体工程——桩功、拳术、炼体、入微——每一步成长都能在身体层面找到对应。
3. **世界层级逐层打开**：从边地江湖到天下武道盘面再到神仙道高位结构，世界不是一次性铺完的，而是跟着寇立的成长一路扩展的。
4. **叩门的意象**：从叩仙门、叩武门、叩身门到叩死门、叩高门，"叩门"是全书最核心的主意象。

## 四、全书时间线

| 阶段 | 时间跨度（估） | 关键事件 |
|---|---|---|
| 阶段1 | 约数月 | 粤州客栈、水龙帮冲突、确认武叩仙门方向 |
| 阶段2 | 约1-2年 | 进入烧身武馆、童子桩入门、猛虎拳成形 |
| 阶段3 | 约2-3年 | 江湖杀局磨砺、三魂掌/九截刀/拳术入身 |
| 阶段4 | 跨度较长 | 进入宗师、武盟大会、朝廷格局、九龙龙气 |
| 阶段5 | 后期 | 神仙道/鬼道/龙气统合、玄刀诀、高位收束 |

## 五、全书空间结构

寇立的活动空间随成长不断扩展：

- **第一圈**：粤州城、客栈、水龙帮地盘、岭南沿海（开篇）
- **第二圈**：烧身武馆、武场、站桩练功场（武道路线落地）
- **第三圈**：江湖杀局现场、山洞山谷等生死磨砺场（拳术验证）
- **第四圈**：武盟大会现场、府邸、朝廷空间、天下武道盘面（层级抬升）
- **第五圈**：九龙山、铜峰、皇宫、鬼城、更高修行场域（高位统合）

空间扩展的规律：不是线性旅行，而是每进入一个新层级，活动半径就实质性扩大一次。

## 六、全书势力版图

| 势力类型 | 代表 | 寇立的关系变化 |
|---|---|---|
| 边地帮会 | 水龙帮 | 从敌对到超越 |
| 武道结构 | 烧身武馆、武盟 | 从进入者到规则参与者 |
| 官方势力 | 朝廷、官府 | 从中立到被卷入再到影响 |
| 修行势力 | 鬼仙宗、天魔道、紫霄派 | 从不知到被追查再到主动接触 |
| 高位存在 | 左圣、神仙道、龙气体系 | 从传闻到直接接触 |

## 七、全书核心关系网

以寇立为中心的关键关系按出现顺序：

**第一圈（早期）**：郑老铁（引路人）、郑宝儿（情感锚）、水龙帮相关人物（早期压迫）

**第二圈（武馆期）**：罗严宗（武道引路）、岳武霍（武馆结构）、赵教习、姜水源、马源（同辈节点）

**第三圈（江湖期）**：刀疤脸、九截刀相关杀手、黄公子（高位关系链起点）

**第四圈（武盟期）**：宗师人物、武盟前十、朝廷盘面关键人物

**第五圈（高位期）**：神仙道、鬼道、龙血龙气线上的高位存在

关系网的换层规律：寇立的关系网不是固定朋友圈，而是随着层级抬升持续换层——这本身就是世界结构在人物层面的映射。
