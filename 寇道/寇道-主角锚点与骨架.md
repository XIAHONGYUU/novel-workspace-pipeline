# 《寇道》主角锚点与骨架

本文件用于在正式拆主角人物卡和词条之前，先稳定确认主角锚点与主角骨架。

## 一、主角锚点

- **本名**：寇立
- **常见称谓**：寇哥哥、师弟、师兄、八师兄、寇书生、寇仙人、寇无敌、寇总管、寻真
- **化名 / 马甲**：林吾道（化名/别号）、心猿寇立（鬼道相关分身/变体）、正阳子转世（转世身份线索）
- **易混简称**：寇、老寇、小寇、寇兄、寇师
- **关键关联名词**：无字图/无字书、武叩仙门、童子桩、猛虎拳、烧身武馆、九龙龙气、玄刀诀

## 三、主角骨架草稿

### 1. 身份底座

寇立的底座是三合一结构：
- **穿越者**：来自现代世界，带有分析思维和现实判断力，但不是全知全能的"先知型"穿越者
- **求仙无门者**：穿越三年仍未踏入任何修行门槛，这种"卡在门外"的处境构成了他最初的精神困局和行动驱动力
- **边地求道人**：落脚于粤州这个暴烈边地，面对的不是温室修行环境，而是江湖帮会、海贸暴利、黑白混杂的现实

这个底座的关键在于：寇立不是"天生该赢"的类型，而是"被逼到必须找到路"的类型。他的每一步前进都来自外部压迫和内部判断的合力。

### 2. 成长引擎

寇立的成长引擎是五引擎咬合结构，不是叠加而是逐层递进：

1. **无字图/无字书**（高位感知引擎）：提供异常感知能力、更高结构线索和"门一定存在"的信心。有风险（反噬），需要驯服。
2. **武叩仙门**（路线判断引擎）：核心方法论——主动确认以武道作为叩开修行大门的主路线。这不是退而求其次，而是方法论创新。
3. **童子桩+猛虎拳**（身体工程引擎）：武道真正落地的第一条主路，桩功提供根基，拳术提供表达，无字图入微能力与身体感知在此咬合。
4. **生死磨砺**（路线校正引擎）：通过三魂掌、九截刀、杀局等实战压力反复检验和打磨武道路线，把拳术从"外学"转化为"己用"。
5. **多体系统合**（高位统合引擎）：后期将武道、神仙道、鬼道、龙血龙气、玄刀诀等体系接合，完成从"武叩仙门"到"武道通高位"的闭环。

### 3. 质变路线

寇立的质变路线不是"数值升级"，而是五次"道路重新定义"：

- **第一次质变**（粤州阶段）：从"求仙无门的空想者"→"确认武道可通仙门的求路者"。标志：武叩仙门的判断。
- **第二次质变**（武馆阶段）：从"找路的人"→"上路的人"。标志：童子桩与猛虎拳的正式入门，拳术开始被身体承载。
- **第三次质变**（江湖阶段）：从"学拳的人"→"拳入身的人"。标志：在杀局中完成拳术从招式到本能的转化，武道路线被死局验证成立。
- **第四次质变**（武盟阶段）：从"地方武人"→"天下武道核心变量"。标志：进入宗师层级、参与武盟大会、在天下武道盘面中获得规则话语权。
- **第五次质变**（高位阶段）：从"单一武道者"→"多体系统合者"。标志：神仙道、鬼道、龙气等高位路线的接入与统合。

### 4. 高位结构

寇立最终进入的高位结构是一条"四线合流"的复杂体系：

- **武道线**：从童子桩、猛虎拳到宗师、武盟，是寇立最稳固的主梁
- **仙道线**：以无字图为起点，逐步进入更高修行结构，与武道并非替代而是互补关系
- **鬼道线**：涉及心猿寇立、鬼城、御鬼等概念，是寇立在精神/灵魂维度的扩展
- **龙气线**：九龙龙气、龙血、朝廷与山河秩序，是寇立接入世界最高秩序的政治-修行双重入口
