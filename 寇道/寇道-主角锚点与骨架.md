# 《寇道》主角锚点与骨架

## 说明

本文件用于在正式拆主角人物卡和词条之前，先稳定确认主角锚点与主角骨架。

## 一、主角锚点

- 本名：寇立
- 常见称谓：寇哥哥、师弟、师兄、八师兄
- 化名 / 马甲：当前已读材料里尚未稳定确认有长期主马甲，后续可在更细致二级词条中继续补
- 易混简称：寇
- 关键关联名词：无字图、郑老铁、郑宝儿、烧身武馆、罗严宗、猛虎拳、武叩仙门、水龙帮、武盟、九龙龙气、玄刀诀

当前阶段可以稳定用于检索和主角追踪的主锚点，就是 `寇立`。

## 二、当前确认依据

- 从 chunk 蒸馏结果看：
  - 首轮诊断报告已将 `寇立` 稳定列为主角候选第一位，粗提及约 `9601` 次
  - 虽然前言污染明显，但污染并没有动摇主角判断，反而从开篇开始就一直围绕寇立推进
- 从 focus 追踪结果看：
  - `寇立` focus 覆盖 `153` 个 chunk
  - 累计提及次数 `8448`
  - 从粤州客栈开局，到后期九龙龙气、武盟、神仙道、铜峰、龙血等高位内容，始终都是主叙事中心
- 从阶段划分看：
  - 这条线至少明显经历了
  - 粤州求道摸索与水龙帮冲突
  - 烧身武馆、童子桩、猛虎拳与武叩仙门
  - 岭南江湖与拳术成熟
  - 武盟与朝廷大盘面
  - 神仙道、鬼道、龙气与更高修行结构

所以当前可以稳定确认：

《寇道》的主角就是 `寇立`。

## 三、主角骨架草稿

### 1. 身份底座

- 穿越者
- 粤州落脚的外来书生 / 客栈住客
- 长期求仙无门、但始终没放弃的人
- 后续进入烧身武馆的武道路线上升者

寇立的开局非常有辨识度。

他不是天生武人，也不是一落地就有大靠山，而是一个已经在这个世界摸索三年、仍然找不到真正门路的穿越者。

他的底色同时带着两层东西：

- 现代人的分析和现实感
- 古代边地江湖中随时可能被碾死的压力感

这让他从一开始就既不空想，也不认命。

### 2. 成长引擎

- 最早的核心异常物：无字图 / 无字书
- 真正稳定的上升路线：武叩仙门
- 具体落地路径：童子桩、猛虎拳、拳术磨砺、暗杀拳法、玄刀诀等
- 中后期重要抬升：鬼道、神仙道、龙血、龙气、五行真气、刀法与更高修行结构

寇立的成长不是单一奇遇推动，而更像是：

- 无字图提供感知和“入微”能力
- 武道提供第一层真正站得住的主路
- 生死磨砺不断把这条路校正得更硬
- 后期再把武道与神仙道、鬼道、龙气体系接起来

### 3. 质变路线

- 第一段质变：从求仙三年无门的外来者，转向确认“武叩仙门”
- 第二段质变：进入烧身武馆，童子桩与猛虎拳真正落地，武道第一次成形
- 第三段质变：从练拳者变成真正能在江湖杀局中站住、并反过来校正自身路线的人
- 第四段质变：进入宗师、武盟、朝廷与更大天下格局
- 第五段质变：武道进一步与神仙道、鬼道、龙气、龙血和更高修行结构打通

这说明寇立这条线的核心，不是纯武学升级，而是不断发生“路线整合”和“层级换轨”。

### 4. 高位结构

- 地方起点：粤州、水龙帮、客栈、烧身武馆
- 武道中层：童子桩、猛虎拳、炼体、宗师、武盟
- 天下大盘面：朝廷、武盟大会、九龙龙气、九州山河
- 高位修行层：神仙道、鬼道、龙血、龙气、玄刀诀、铜峰、灵器

也就是说，《寇道》并不是停在江湖打斗里，而是明显会一路抬升到武道与神仙道混合的大结构。

## 四、当前最值得拆的一级词条

- 身份变化
- 无字图 / 核心机缘路线
- 武叩仙门与武道路线
- 战斗方式
- 修行 / 炼体 / 神仙道高位路线
- 世界结构
- 势力与局势卷入
- 重要关系网
- 重要城市与地域轨迹

## 五、当前阶段性理解

寇立这条主角线目前最值得抓住的，不是他认识了哪些人，而是下面这条主干：

- 穿越后求仙三年无门
- 在粤州江湖现实中确认武道是可行入口
- 用童子桩、猛虎拳、暗杀掌法和各种实战磨砺把“武叩仙门”练成真的路
- 中后期再把武道、神仙道、鬼道、龙血与龙气逐步接起来

这意味着《寇道》的整理方向，必须按“主角优先法”推进：先抓寇立的求道路线，再让词条从这条路里长出来。

## 六、当前结论

当前已经可以稳定确认，《寇道》的主角就是 `寇立`。

而从现有 focus 和原文骨架看，这不是一个单纯“江湖拳师成长”的故事，而是一条从粤州边地和水龙帮乱局起步，经由武叩仙门一路推进到宗师、武盟、神仙道、龙气与更高修行结构的主角线。
