# 《寇道》最吸引人的十个剧情细节总表

## 说明

本表从《寇道》全书中提炼出十个最具吸引力的剧情节点（高光桥段），每个节点按"发生了什么 → 为什么吸引人 → 在全书中的位置"三维度进行评估。
