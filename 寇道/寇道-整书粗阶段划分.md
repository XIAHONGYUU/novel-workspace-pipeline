# 《寇道》整书粗阶段划分

## 说明

本文件用于在第一轮 chunk 蒸馏基础上，给整本书建立后续可复用的粗粒度阶段骨架。

当前版本优先服务于三件事：

- 稳定寇立的成长主轴
- 给后续一级词条提供分段框架
- 让总索引、核心体系总览与二级词条有共同参照

这本书的标题抽取质量一般，前言污染明显，所以本阶段划分以正文实际内容、主角位置变化和力量结构抬升为准，而不是机械依赖自动 chunk 标题。

## 阶段总览

### 阶段 1：粤州开局与求道摸索期

- 起止 chunk / 章节：约 `chunk-0001` 到 `chunk-0025`；约正文开篇到入烧身武馆前后
- 划分依据：寇立在粤州客栈、水龙帮冲突、郑老铁出现、无字图线索与“求仙无门”的现实困境共同构成开局底座
- 主角在这个阶段的状态：穿越后长期摸索求仙，三年无门，表面冷静，内里极强烈地想要找到真正的上升之路
- 主要地点 / 场域：粤州、客栈、水龙帮地盘、南天门山与周边岭南地界
- 主要矛盾：水龙帮现实压迫、江湖暴力冲突、求仙不得、无字图不开光
- 主要抬升：确认“神仙道难入”，开始把“武叩仙门”作为可走道路；郑老铁、郑宝儿和无字图同时成为后续主线入口

### 阶段 2：烧身武馆与武叩仙门成形期

- 起止 chunk / 章节：约 `chunk-0026` 到 `chunk-0060`
- 划分依据：进入烧身武馆后，寇立开始真正接触童子桩、拳术、罗严宗、岳武霍等武道结构，“武叩仙门”第一次成为稳定自觉
- 主角在这个阶段的状态：从求道无门的外来者，转成主动用身体、拳术和意志为自己打出道路的武道路线上升者
- 主要地点 / 场域：烧身武馆、武场、观潮地带、练桩与习拳空间
- 主要矛盾：根基不稳、资质并不出众、传统学徒路径缓慢，与自身极强上升欲望冲突
- 主要抬升：童子桩、猛虎拳、站桩入劲、无字图“入微”能力开始和武道修行真正咬合

### 阶段 3：岭南江湖与拳术成熟期

- 起止 chunk / 章节：约 `chunk-0061` 到 `chunk-0095`
- 划分依据：寇立开始把拳术真正练进身上，并在生死磨砺里校正无字图、拳术和自身意志的关系
- 主角在这个阶段的状态：从单纯学徒转向真正敢以拳术、生死、狠劲去验证自己的行动者
- 主要地点 / 场域：粤州、山洞、沿海地带、各类江湖冲突空间
- 主要矛盾：江湖暗杀、三魂掌这类凶险打法、无字图对武道的帮助与反噬风险、如何让“外力”变成“己身”
- 主要抬升：猛虎拳由入门推到精通，三魂掌、九截刀、暗杀拳体系等内容开始介入，寇立第一次真正完成“以武为本”的自我校正

### 阶段 4：武道高层与朝廷 / 武盟结构期

- 起止 chunk / 章节：约 `chunk-0096` 到 `chunk-0125`
- 划分依据：主角不再只是岭南地方高手，而开始进入更高武道层级、武盟大会、宗师序列与朝廷相关盘面
- 主角在这个阶段的状态：已经不是地方学徒，而是足以改写武道格局、被高位武人认真看待的人物
- 主要地点 / 场域：中原、武盟大会、府邸、朝廷与宗师相关场域
- 主要矛盾：武道高层排序、宗师与朝廷内定结构、主角如何从江湖高手进一步进入天下格局
- 主要抬升：拳术、宗师、武盟、朝廷、九爪金龙与山河龙气等内容开始汇聚，世界盘面被明显拉大

### 阶段 5：神仙道、鬼道、龙气与高位结构期

- 起止 chunk / 章节：约 `chunk-0126` 到 `chunk-0153`
- 划分依据：寇立的路线已不再只是纯武道，而是全面接入神仙道、鬼道、龙血、龙气、铜峰、玄刀诀和更高修行结构
- 主角在这个阶段的状态：从武叩仙门的武者，转成真正踏入神仙道高位结构、并尝试把武道与修行路打通的人
- 主要地点 / 场域：皇宫与九龙龙气相关场域、铜峰、山腹、海外蛟龙与各类高位修行空间
- 主要矛盾：武道与神仙道的统合、龙血龙气与更高玄功之间的关系、如何以自身道理接入更高秩序
- 主要抬升：心猿、龙气、龙血、鬼城、灵器、玄刀诀、五行真气等内容共同出现，主角线正式进入高位武道与修行混合结构

## 主角成长主轴压缩版

把全书压成一条最核心的成长线，大致就是：

- 穿越后在粤州三年摸索修仙却始终入门无路
- 在水龙帮、郑老铁、无字图等事件推动下，确认“武叩仙门”这条路
- 进入烧身武馆，用童子桩、猛虎拳和生死磨砺把武道真正练进身体
- 从岭南地方江湖一步步打进更高武道层与朝廷 / 武盟格局
- 后期把武道、鬼道、神仙道、龙气、龙血与更高修行结构进一步打通

## 当前结论

《寇道》的主角线不是普通的“从江湖到修仙”流水升级，而是一条以“武叩仙门”为总骨架，从粤州江湖、烧身武馆、武道宗师层一路抬升到神仙道与龙气高位结构的混合上升线。
