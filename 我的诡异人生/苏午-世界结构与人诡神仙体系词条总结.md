# 苏午世界结构与人诡神仙体系词条总结

## 说明

《我的诡异人生》的世界非常复杂，但从苏午主角线来看，真正要抓的是“世界如何一层层打开”。

## 一、现实诡灾层

故事最开始不是高天大战，而是现实生活中突然渗出的诡异。

这一层的关键词是：

- 影诡
- 三清之肠
- 城市与乡村中的诡灾
- 普通人如何在诡异里活命

## 二、过去人生入口层

模拟器带来的过去人生功能，让世界不再是单一现实。

从这里开始，苏午可以横向切入不同体系、不同时间和不同文化背景中的传承。

## 三、密藏域佛法与容诡层

密藏域是全书第一次真正意义上的体系换层。

在这里，世界结构包含：

- 佛寺
- 呼图克图
- 供物
- 系缚
- 命格
- 容诡修行

## 四、东流岛刀兵与鬼神层

东流岛则打开了另一层世界：

- 杀生石
- 铸刀师
- 鬼神锻法
- 神社与家族结构

这一层让世界更偏向刀兵、锻造和神异技艺。

## 五、现实民俗、庙系与香火层

再往上，世界逐渐把现实中的民俗宗教、香火庙系和灶神教等体系卷进来。

这一层说明，全书的世界从来不是单一佛门或单一道门，而是高度混融的。

## 六、赤龙、黑傩、人道与高层秩序层

到了中后期，世界结构继续抬升。

这时已经要理解：

- 赤龙
- 黑傩
- 道门与天师道
- 人道宗庙
- 真性与法性

## 七、三清、大天与终局层

最终还要再往上看一层：

- 三清
- 元河
- 大天
- 元皇
- 诸我归一

这里已经不是单纯设定扩张，而是世界根本秩序的问题。

## 八、总结

苏午的世界结构线，可以压成最短路径：

现实诡灾 -> 过去人生入口 -> 密藏域佛法与容诡体系 -> 东流岛刀兵与鬼神体系 -> 现实民俗与香火庙系 -> 赤龙黑傩与人道高层 -> 三清大天与终局秩序。

这条线，是理解《我的诡异人生》为什么能从现实诡事一路推到宇宙终局而不散架的核心骨架。
