# 苏午势力与传承卷入词条总结

## 说明

苏午这条线真正厚重的地方，不只是他碰到很多势力，而是这些势力和传承最后都在他身上发生了汇流。

## 一、现实起点并无稳定后台

苏午开始时没有现成大宗门、大组织做依托。

这反而让他后面卷入势力时，更显得是靠自己一步步进去的。

## 二、密藏域是第一次真正卷入大体系

密藏域与无想尊能寺，是苏午第一次真正卷入完整传承结构。

这一层的重要性在于：

- 不是单独学一个法门
- 而是进入一个自成体系的文明与修行秩序

## 三、东流岛补足另一条传承线

东流岛过去人生，则让苏午接入另一条完全不同的体系：

- 杀生石
- 铸刀所
- 源氏家族
- 鬼神锻法

这一步让苏午不是单脉成长，而是横向吸收。

## 四、灶神教与现实师承让主线归位

苏午后面真正“落地”的重要一环，是李岳山、云霓裳和灶神教等现实传承线。

这一层使他从“到处取法的人”变成“在现实中真正承脉的人”。

## 五、赤龙、黑傩与道门让格局再抬一层

再往后，赤龙、黑傩、道门和更多人道脉络汇入后，苏午已经不再是在不同传承之间游走，而是在逐渐成为多条主干的汇流点。

## 六、总结

苏午的势力与传承卷入路线，可以压成最短路径：

无后台的现实求生者 -> 卷入密藏域与无想尊能寺 -> 切入东流岛铸刀与锻法体系 -> 灶神教和现实师承归位 -> 赤龙、黑傩、道门与人道主干汇流。

这条线解释了苏午为什么后面能承住那样大的格局。
